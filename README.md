## ✨ Features

| | Page | What it is |
|---|---|---|
| 🏠 | [Home](https://caputodavide93.github.io/between-stops-site/) | What the app is, in three lines |
| 🔒 | [Privacy policy](https://caputodavide93.github.io/between-stops-site/privacy/) | What the app keeps, every optional permission, and what can leave the phone. Linked from the app and the store listings |
| ✉️ | [Contact](https://caputodavide93.github.io/between-stops-site/contact/) | Support address and common questions. Linked from the app and the store listings |
| 🌗 | Light and dark | Follows the reader's system setting |
| 🚫 | No tracking | No scripts, cookies or analytics |

## 🚀 Quick Start

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

GitHub Pages publishes the `main` branch root.
